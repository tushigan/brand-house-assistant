# 大众烘焙品牌完整提报复盘（脱敏案例）

> 本案例根据一个已完成交付的大众烘焙品牌项目整理，已移除品牌名称、客户姓名、原始录音、具体合作方和未授权的企业资料。它用于学习方法，不是任何新品牌的事实来源。

## 一、案例定位

- **项目阶段：**品牌屋整理、现场提报逐字稿和 HTML 演示稿交付
- **最终交付：**29 页提报稿，包含 MVV 阶段小结、定位阶段小结和完整品牌屋总结页
- **主要训练目标：**学习从文化线索和企业基础推导品牌屋，并把上下层支撑关系讲给客户听
- **案例状态：**交付案例复盘；具体企业事实和客户裁决不外推

## 二、原始问题

品牌已有制造、价格带和供应链积累，但缺少一套把文化、业务能力、产品价值和后续经营判断串起来的品牌屋。项目不是凭空重塑品牌，而是要把已有的价格优势重新解释为消费者可以感知和信任的价值。

需要回答：

1. 品牌希望创造怎样的长期未来？
2. 品牌为什么存在？
3. 在什么品类、面向什么场景和人群竞争？
4. 消费者为什么选择它？
5. 企业如何长期把差异化价值做出来？

## 三、推导主链

```text
文化与普惠线索
→ 愿景、使命、价值观
→ 竞争战场与参照对象
→ 细分品类、消费场景、核心人群
→ 单一差异化价值“更有质价比”
→ 品牌定位“民生品质烘焙”
→ 产品、体验、背书三类 RTB
→ 内部品牌主张“把价格做实，把品质做足”
→ 品牌个性与沟通语言
→ 后续再推导消费者口号
```

## 四、阶段性品牌屋结论

| 层级 | 脱敏后的结论示例 | 如何检查 |
|---|---|---|
| 愿景 | 愿天下人，一餐一食，皆得其养 | 是否形成可想象的长期生活画面 |
| 使命 | 让人人都能吃上好糕点 | 是否回答品牌为什么存在 |
| 价值观 | 务实、公道、共赢 | 冲突场景下能否指导取舍 |
| 品类／场景 | 早餐型包装烘焙；早餐、代餐、日常充饥 | 消费者是否按此理解购买任务 |
| 核心人群 | 精打细算但希望日常吃得有品质 | 是否真实影响选择和复购 |
| 差异化价值 | 更有质价比 | 相对谁、按什么品质基准成立 |
| 品牌定位 | 民生品质烘焙 | 是否能指导产品、价格、渠道和传播取舍 |
| 品牌主张 | 把价格做实，把品质做足 | 是否能指导内部产品和经营判断 |
| 品牌个性 | 沉静专注、朴实真诚、温厚坚定 | 是否能回溯到可观察行为 |
| 沟通语言 | 真实克制、清楚易懂、温和坚定 | 消费者是否听得懂且不被教育 |
| 品牌口号 | 本轮暂不纳入 | 是否承接主张、个性和消费者理解方式 |

上述内容是项目中的阶段性品牌屋结构示例。新项目必须重新核对品牌主体、证据状态、适用周期和最终裁决人。

## 五、RTB 的处理方式

### 产品证据：有能力做出来

成熟制造体系不只等于工厂、设备和生产线，还应包含供应商筛选、协同和稳定供给。它要解释企业如何在控制成本的同时保持生产效率、交付和品质。科学选品体系和分层质量控制属于需要分别判断的内在能力，不能因为企业“有数据”或“有设备”就直接写成已验证优势。

### 体验证据：消费者感受得到

把企业能力翻译为消费者能直接感知的价值，例如美味尝得到、品质可溯源、产品信息和分量实在可感知。每条体验证据都要说明消费者在哪里看到、吃到或比较到它。

### 背书证据：外部依据可信

国际合作、专业认证、资质荣誉等只能作为外部背书，不能替代产品能力和体验证据。最终要用一句收束：产品证据证明有能力做出来，体验证据证明消费者感受得到，背书证据证明外部依据信得过。

## 六、现场提报的讲法

### “为什么—是什么—为什么是这样”

每页先说明这一层要解决的问题，再给出本页结论，最后解释它如何由上层推出、又支撑下层。这样品牌屋不会变成一张孤立的词语表。

### 口语化不是不专业

提报逐字稿可以保留设问、对照、比喻和有目的的重复。要删除的是空洞口头噪声，不是所有口语表达。听众需要先听懂推导，再记住结论。

### “共赢”的准确解释

“共赢”对应《高效能人士的七个习惯》中的“双赢思维”。“你不赢，我不赢”是项目对这个原则的业务化转译，不是书中原句。它强调不走“我赢你输”或“我输你赢”，而是在消费者、渠道、供应商和企业之间寻找可持续的合理价值关系。

## 七、走偏与修正

| 原先走偏 | 修正方向 |
|---|---|
| 用“国民品牌”概括全部定位 | 回到竞争对象、品类、场景和人群 |
| 把“高性价比”直接当答案 | 说明品质基准、比较对象和可验证 RTB |
| 把普惠口号当差异化定位 | 分回使命、品牌定位和消费者利益层级 |
| 只列工厂、设备、证书 | 加入供应商协同、消费者体验和内在能力 |
| 先做口号 | 先完成主张、个性和沟通语言 |
| 只给品牌屋图片 | 用逐字稿讲清每一层的支撑关系 |

## 八、可复用的白话提问

1. 我们到底和谁竞争，消费者现在拿什么来替代我们？
2. 这个品类是消费者会用的说法，还是内部分类？
3. 目标人群在什么场景下会因此选择和复购？
4. “更有质价比”相对谁、按哪些指标、在哪个价格带成立？
5. 企业现在已经具备什么，哪些只是接下来要建设？
6. 这一层结论具体支撑品牌屋的哪一层？

## 九、使用边界

- 只借鉴推导顺序、证据处理、提问方式和提报讲法。
- 不把本案例中的品牌结论、价格带、竞争对象、企业事实或口号直接复制给其他项目。
- 所有对外表达都要回到当前项目的原始材料、食品合规和有权人员裁决。
