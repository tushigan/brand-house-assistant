# 案例库索引

案例库用于三件事：学习完整推导、训练白话提问、做审核和 Skill 回归测试。案例不是其他品牌的事实数据库，也不是把客户项目答案直接复制出去的素材库。

## 使用规则

当用户询问“最佳实践”“案例”“范例”或“以前是怎么做的”时：

1. 先读取本索引，列出与当前任务最匹配的案例。
2. 再读取对应案例全文，不要只看 `test-prompts.json`。
3. 明确区分案例中的当前事实、策略判断、待验证项、目标状态能力和最终裁决。
4. 只借鉴推导顺序、提问方式、证据处理和提报讲法，不把案例品牌结论直接复制到新项目。
5. 如果没有匹配案例，明确说明案例库缺少该类型完整案例，再回到方法原典或用户提供的项目原始材料。
