# 品牌屋20份工具索引

> 仅供公司内部培训与咨询项目使用，请勿外传。  
> 使用原则：先确认独立品牌和战略周期，再按章节顺序使用；任何“待验证／待建设”都必须写责任人、方式和期限。HTML工具的草稿只保存在当前浏览器本机，不会自动同步到团队或云端，正式评审前请打印或另行归档。

## 一、推荐使用顺序

```text
品牌边界与阶段
  → 材料审计与品牌考古
  → 独立品牌MVV
  → 品类、客群场景与“更XX”
  → 品牌定位与RTB
  → 主张、人格与口号转译
  → 业务和组织行为转译
  → 自下而上验证、版本复盘与重审
```

## 三、项目归档要求

1. 每次正式评审须保存工具版本、填写日期、负责人和裁决人。
2. 浏览器本机草稿不能作为团队唯一档案；请打印为PDF或复制到受控项目目录。
3. 工具之间发生冲突时，保留冲突两端原文，不直接覆盖旧结论。
4. 品牌屋主图只保存目标状态；当前事实、能力缺口和项目计划统一进入工具17。
5. 只有差异化价值字段强制“更XX”；品牌定位、品牌主张、品牌口号、产品口号和战役广告语按各自职责判断。
6. 食品、营养、健康、比较、认证、检测和第三方引证进入外部页面前，必须按最终可见原句、具体SKU、渠道与日期重新审查。
