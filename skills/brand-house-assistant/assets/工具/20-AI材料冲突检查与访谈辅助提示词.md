# 工具20｜AI材料冲突检查与访谈辅助提示词

> 对应第17、18章｜公司内部资料，请勿外传。

## 使用边界与适用范围

本工具只帮助项目组从已授权材料中发现可能冲突、缺项和可继续追问的问题，并协助准备访谈。AI输出是**待核线索**，不是事实、证据、食品合规意见、用户验证结论或品牌屋裁决。AI不能替代原始材料回读、访谈、事实核查、用户验证和人工最终裁决。

- 只能输入已获授权、已脱敏的材料；不要输入个人信息、未公开配方、账号密码、原始经营数据或不必要的供应链信息。
- 每条AI提示必须回到原始材料核对原句、来源、日期和适用范围；无法回读时，证据状态标“待验证”，并在理由中写“未提供”。
- AI不能判定Wokenday已经具备任何产品、数据、RTB或竞争优势；不能替巴比熊补写历史、MVV、定位或产品事实。
- 涉及营养、健康、安全、疾病、添加剂、认证和广告／标签的内容，AI不能作合规结论，必须交由事实核查与专项合规流程处理。

## 使用说明

1. 先建立材料清单：文件名、日期、作者／来源、权限、适用品牌与已知状态。
2. 仅把最小必要、脱敏后的文字粘入下方提示词；每次只处理一个独立品牌和一个战略周期。
3. 要求AI按“原文摘录—可能冲突—待核问题—需要谁确认”输出，禁止其补全未知事实。
4. 记录AI结果的材料编号；由人工逐条回读原文并填写工具18或工具19。
5. 最终只有品牌负责人、事实核查人和裁决人可以填写正式裁决；验证任务与能力建设任务必须写在各自字段，不能混入裁决。

## 提示词一：材料冲突检查（可复制）

```text
你是内部品牌屋项目的材料整理助手。只比较我提供的材料，不使用外部知识，不补写任何事实。

项目边界：独立品牌【品牌名】；战略周期【周期】；本次检查字段【MVV/定位三角/RTB/主张/人格/口号/触点】。
内容性质：当前事实／策略假设
证据状态：已证实／待验证
能力状态：已具备／待建设
裁决状态：待裁决／保留／退回／淘汰

请严格执行：
1. 每一个判断都引用材料编号和最小原文摘录；没有原文则写“未提供”。
2. 找出同一字段在不同材料中的用词、对象、时间、范围、内容性质、证据状态、能力状态、裁决状态和因果关系冲突。
3. 不判断哪一方为真；只列“需要人工核对”的问题与推荐核对对象。
4. 不把课堂口述、AI推断或计划写成当前事实；不得生成食品、营养、健康、安全、认证或法规结论。
5. 差异化价值字段如出现正式候选，检查是否以“更”开头，并提示还需核对：对手明确、用户重要、选择有效、RTB成立、相对持续；不要把此规则用于定位、主张或各类口号。

按下表输出：
|字段|材料编号与原文摘录|可能冲突或缺项|内容性质|证据状态|能力状态|裁决状态|人工核对问题|建议核对角色|

材料：
【材料编号、日期、来源、脱敏文本】
```

**输入：** 脱敏材料、品牌边界、战略周期、待检查字段。  
**输出：** 冲突线索与人工核对清单。  
**事实边界：** 输出不构成事实判断；逐条回读原始材料后再写入工具18或19。  

## 提示词二：品牌考古访谈准备（可复制）

```text
你是内部品牌屋访谈准备助手。根据我提供的脱敏材料，为【独立品牌】生成“需要求证”的访谈问题，不要编造该品牌的历史、产品、MVV、用户或经营事实。

目标：区分企业层与品牌层；确认品牌愿景、使命、价值观是否有真实故事；找出定位三角、RTB、主张和触点中需要补证的内容。

请输出：
1. 访谈对象建议（创始人/老员工/产品质量/渠道服务/用户等）以及每类对象能核对什么；
2. 每类对象5个以内的开放问题，优先追问具体事件、可选方案、代价、反例、原始记录和时间；
3. 每个问题对应的材料编号与待验证字段；
4. 不应问或不应预设的内容；
5. 会后应索取的最小证据清单。

禁止：把候选词当成既有结论；把“更XX”当作所有表达的强制句式；给出食品、健康、营养或法规结论；用AI回答代替受访者与原始材料。

材料：
【材料编号、日期、来源、脱敏文本】
```

**输入：** 已授权的历史材料／会议记录／空白项。  
**输出：** 访谈提纲和最小取证清单。  
**事实边界：** 访谈回答仍是待核材料；需记录原话、来源、反证与裁决。  

## 提示词三：目标状态与能力缺口整理（可复制）

```text
只基于以下脱敏材料，帮助整理“当前事实—目标状态—能力缺口”。
独立品牌：【品牌名】；战略周期：【周期】。

规则：
- 当前事实必须有材料编号和原文摘录；没有则将证据状态标为“待验证”，并在理由中写“未提供”。
- 目标状态必须分别记录内容性质、证据状态、能力状态与裁决状态，不得把策略假设写成当前事实，也不得把待建设写成已具备。
- 能力缺口按产品证据、体验证据、背书证据、组织能力分栏，并为每项提出“需由谁以何种原始材料验证”的问题。
- 不生成或推断品牌历史、经营数据、产品能力、营养健康安全结论或对外承诺。

请输出工具17可填写的表格草案：
|字段|当前事实与来源|目标状态|内容性质|证据状态|能力状态|裁决状态|能力缺口|人工验证方式与责任角色|

材料：
【材料编号、日期、来源、脱敏文本】
```

**输入：** 已知材料与目标周期。  
**输出：** 工具17的待核草案。  
**事实边界：** 任何“当前事实”必须人工回读；任何目标状态都不能直接用于对外声称。
