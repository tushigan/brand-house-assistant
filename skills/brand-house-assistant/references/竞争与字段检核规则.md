# 竞争与字段检核规则

这份参考规则用于审查已有品牌屋、品牌共创和版本重审。它把“好听但不可执行的说法”转成可判断的检查动作。

## 一、竞争参照

### 定位推导顺序

定位不能从一个听起来好的利益词开始。建议按以下顺序推进：

> **竞争战场与参照对象 → 细分品类 → 消费场景与核心人群 → 希望占据的心智 → 差异化价值与RTB**

如果用户先提出“安心、好吃、性价比”等词，先把它们当作待比较的利益候选，退回上游确认这些词分别要解决哪种竞争；不能先选词再倒找理由。

先回答四个问题：

1. 具体要赢谁，或替代什么方案？
2. 对方在消费者、渠道或经销商端占据什么核心认知？
3. 目标品牌要抢哪一个认知位置？
4. 哪些比较维度不能与对方重复，否则无法形成差异？

“杂牌”“其他品牌”“同类品牌”只能作为待拆分的线索，不能作为正式竞争对象。竞争对象可以是具体品牌、可验证的品牌群，或明确的替代行为，但必须能被团队继续取证和复核。

### 最小可行性门槛

完整RTB可以后置，但候选竞争战场不能完全不做检查。每个候选至少回答：

- 有没有基本产品基础；
- 供应和质量能否承接；
- 目标渠道能否触达目标人群；
- 在本战略周期内是否有规模或重复购买机会。

这只是继续研究的门槛，不是现有优势证明，也不能替代后续产品、体验、背书和内在能力的RTB验证。

## 二、独特利益

独特利益是一个主导竞争认知，不是卖点清单。每个候选至少填写：

- 相对谁更什么；
- 这件事对目标用户是否重要；
- 是否会影响选择；
- 当前或目标状态 RTB 是否能支撑；
- 其他“品质、实惠、讲究、好吃”等词降级到什么位置。

如果多个候选只是同义改写，合并而不是并列。没有明确竞争参照、用户选择影响或兑现路径时，保留为策略假设／待裁决。

## 三、字段层级归属

审核或共创时，先给每条表达归层，再判断是否成立：

| 层级 | 主要回答 | 常见误放 |
|---|---|---|
| 品牌级价值／情绪收益 | 用户最终获得什么价值感受 | 把“购买后的放心”直接写成品类定位 |
| 品类定位 | 用户把品牌当作哪一种产品或解决方案 | 把“蛋糕”这种宽泛品类当作完整竞争战略 |
| 消费场景 | 谁在什么时刻、为何需要 | 用“日常”代替具体场景和购买行为 |
| 差异化利益 | 相对谁，用户为什么选择 | 把多个利益并列成多个独特利益 |
| RTB证据 | 为什么相信品牌能做到 | 用证书、规模或口述替代完整能力链 |

若一句话混有多个层级，先拆成多条记录，再分别标注状态、证据和回退位置。

## 四、愿景与使命的检核句

建议把字段和检核句分开写：

| 字段 | 检核句要回答什么 |
|---|---|
| 愿景 | 团队能否描述一个具体、可想象、可观察或可量化的未来画面？ |
| 使命 | 团队能否用一句话回答“为什么存在、为谁创造什么长期价值”？ |
| 价值观 | 在真实取舍中，团队会坚持什么、拒绝什么？ |
| 定位 | 相对明确竞争参照，品牌要占据哪个品类／人群／场景位置？ |
| 差异化价值 | 用户会因哪个主导认知选择品牌，而不是因为一串并列好处？ |
| RTB | 哪些产品、体验、背书和内部能力让用户有理由相信？ |
| 品牌个性 | 这个词对应哪些可观察的组织行为和表达方式？ |
| 品牌主张 | 是否从竞争视角把独特利益说成对外承诺？ |
| 品牌口号 | 是否短、稳定、可长期使用，并且没有超出品牌主张？ |

## 五、RTB的内外双层

RTB至少同时检查：

- 产品证据：配方、工艺、品质、检测和稳定性；
- 体验证据：口感、使用场景、服务和复购反馈；
- 背书证据：认证、合作、渠道或第三方评价；
- 内在能力：供应链、测品／选品、研发、组织流程和持续优化能力。

外部证据只能证明“发生过什么”或“谁认可”，不能自动证明品牌能持续兑现利益。未来要建设的能力单列能力建设表，写明责任人、期限和验证标准。

## 六、品牌个性的行为化

每个个性词至少配一条行为证据：

- 做什么取舍；
- 拒绝什么诱惑或短期动作；
- 在产品、渠道、内容或组织管理中如何被看见。

例如“沉心修炼”不能只作为形容词，应继续追问：是否表现为长期打磨供应链、坚持测品、不过度追逐短期热点，或其他可回读行为。没有行为证据时只能作为候选人格，不得直接定稿。

## 七、内部决策工具验收

用四个情境回测品牌屋：

1. 新产品是否符合品牌边界和独特利益？
2. 新价格带变化时，核心竞争机制是否仍然成立？
3. 新传播内容是否强化主导认知，而不是重新堆卖点？
4. 新组织动作是否具备兑现 RTB 的能力？

如果四个情境都只能得到“看情况”，说明品牌屋缺少检核标准、竞争参照或能力约束。
